A simple desktop utility to manage gaming time and encourage quiet play.

### How it works:
* **Time Limit:** Automatically closes Roblox after 60 minutes of daily play.
* **No Screaming:** Monitors microphone volume. If you shout or scream, 5 minutes are deducted from your playtime.
* **Alerts:** Displays a popup notification when your time is up or if a penalty is applied.

### Setup:
1. Run the `.jar` file using `javaw` to keep it in the background.
2. The app saves your progress in `guard_stats.properties` so it won't reset if you restart your PC.
